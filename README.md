# موقع مركز مندور الطبي — Mandour Medical Center

موقع ثابت (Static HTML/CSS/JS) لا يحتاج أي عملية بناء (Build) — جاهز للرفع مباشرة.

## الملفات
```
mandour-medical-center/
├── index.html                 الصفحة الرئيسية (كل الأقسام)
├── dental-center.html         صفحة مركز الأسنان
├── specialty-template.html    قالب TEMPLATE لأي تخصص جديد (انسخه وعدّل)
├── doctor-template.html       قالب TEMPLATE لملف طبيب جديد (انسخه وعدّل)
├── articles.html              صفحة المقالات (نموذجية)
├── css/style.css              نظام التصميم الكامل (Design System)
├── js/i18n.js                 تبديل اللغة عربي/إنجليزي (RTL/LTR)
└── js/main.js                 القائمة، الأكورديون، نموذج الحجز
```

## رفع الموقع على GitHub Pages
1. أنشئ Repository جديد على GitHub (مثال: `mandour-medical-center`).
2. ارفع كل الملفات والمجلدات كما هي (حافظ على بنية `css/` و`js/`).
3. من إعدادات الـ Repository: **Settings → Pages → Branch: main → root** ثم Save.
4. بعد دقيقة أو دقيقتين سيكون الموقع متاحًا على رابط مثل:
   `https://<username>.github.io/mandour-medical-center/`
5. لربط دومين خاص بالمركز، أضف ملف `CNAME` بداخله الدومين، ثم اضبط DNS كما توضح وثائق GitHub Pages.

## ما يجب إكماله قبل النشر النهائي
كل نص بين قوسين `[ ]` هو Placeholder ويجب استبداله ببيانات حقيقية:
- رقم الهاتف، رقم واتساب، البريد الإلكتروني، مواعيد العمل (في الـ Header والـ Footer وقسم التواصل).
- أرقام الإحصائيات في قسم "أرقام المركز" (لا تُستخدم أي أرقام حتى تؤكدوها).
- بيانات الأطباء الحقيقية وصورهم (استبدل بطاقات "صورة الطبيب" التجريبية).
- شركات التأمين المتعاقد معها فعليًا.
- رابط خرائط Google Maps الفعلي للمركز (استبدل الـ `map-frame`).
- الصور الحقيقية للمركز بدل الأماكن المُعلَّمة (Placeholders).

## صفحات القوالب (Templates)
- **specialty-template.html**: انسخه لكل تخصص جديد (الباطنة، التمريض، التحاليل...) وأعد تسميته، ثم أضف رابطًا له من قسم "التخصصات الطبية" بصفحة `index.html`.
- **doctor-template.html**: انسخه لكل طبيب وأعد تسميته (مثال: `dr-ahmed-mansour.html`)، ثم اربطه من بطاقة الطبيب المناسبة.

## الحجز الإلكتروني
نموذج الحجز في `index.html#book` يعمل حاليًا بعرض رسالة تأكيد فقط (بدون إرسال فعلي). لتفعيله بالكامل يمكن ربطه بأحد الخيارات التالية عبر `js/main.js`:
- إرسال البيانات إلى رقم واتساب العمل (WhatsApp Business API).
- خدمة بريد إلكتروني (مثل Formspree أو EmailJS).
- Google Sheets عبر Google Apps Script Webhook.
- نظام إدارة المركز (CRM) الخاص بكم، إن وجد API له.

## زر واتساب العائم
الرابط الحالي `https://wa.me/20000000000` — استبدل الرقم برقم واتساب المركز الفعلي (بصيغة دولية بدون + أو أصفار زائدة، مثل `201xxxxxxxxx`).

## لوحة الإدارة (CMS)
هذا الإصدار موقع ثابت بدون لوحة إدارة مدمجة، حتى يسهل رفعه فورًا على GitHub. لإضافة إدارة سهلة للمحتوى (الأطباء، التخصصات، المقالات، التأمين) دون الحاجة لمبرمج في كل تعديل، الخيارات المتاحة لاحقًا:
- ربط الموقع بـ Headless CMS (مثل Netlify CMS / Decap CMS) يعمل فوق نفس ملفات GitHub مباشرة.
- تحويل المشروع إلى موقع مبني بـ Next.js أو مشابه مع لوحة إدارة مخصصة.

## SEO
كل صفحة تحتوي على Meta Title وMeta Description قابلة للتعديل، بالإضافة إلى بيانات Schema.org (MedicalClinic / Physician / MedicalSpecialty) كنقطة بداية — استكملها ببياناتكم الحقيقية.
